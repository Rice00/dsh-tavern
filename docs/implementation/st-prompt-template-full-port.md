# ST-Prompt-Template 完整接入

## 状态（2026-09-15）

完整上游插件已接入正式游戏流程，自制 QuickJS/EJS 实现已删除。上游 handler、command、ui、exports、code-editor 五个入口全部运行，不再保留另一套模板求值实现。

固定上游提交：`d6f520d149aba146305b0b781ddd691d449c28d2`，manifest 1.17.9。51 个上游源文件保持原样；构建、宿主服务和持久化适配独立放在 `host-build`。

## 正式链路

| 环节 | 接入方式 |
| --- | --- |
| 开场 | 独立临时实例执行上游初始变量，结果写入开场草稿 |
| 玩家输入 | 召回前执行上游消息事件；待提交正文及变量存入原生 Chat；生成完成后合入一条用户消息，重试复用 |
| 世界书 | 官方加载事件、装饰符、预处理、主动激活、嵌套模板及变量函数 |
| 前后台请求 | 所属游戏实例执行官方生成事件，投影到实际原生请求；兼容模式使用相同入口 |
| 消息显示 | 官方渲染事件；显示 HTML 交给实际消息 Frame，隐藏格式化镜像不执行卡片脚本 |
| 永久改写 | 通过原生 Session 的 surface replace 追加事件更新历史，保留非文本块；重启后仍有效 |
| 编辑/版本/回退 | 比较权威快照，触发编辑、swipe、删除及聊天更新事件；持久化每个版本的处理标记和变量 |
| 命令 | 原生注册 `/ejs`、`/ejs-refresh`；模板可调用宿主已注册命令。发起生成的命令在提交后返回，避免占住模板队列 |
| 设置/编辑器 | DSH Tavern 设置中的“提示词模板设置与编辑器”；使用同一个上游实例，Monaco、保存/取消、条目保存均接通 |
| 可选后台编译 | 将上游固定 Worker 路径映射到本地资源，使用同一上游 EJS 编译器 |

## 状态与运行边界

- 浏览器需保持当前游玩页面在线。切换游戏释放旧实例，重连重新读取原生状态；没有旧引擎静默回退。
- Chat、消息/swipe 变量和模板处理标记仍由原生存储与 Journal 保存；全局变量和设置使用原有 Profile 存储。保存使用版本基线合并，拒绝冲突及迟到结果。聊天、全局变量、设置不是跨文件原子事务。
- 世界书关键词召回、预算、十轮冷却和固定/动态注入位置保留 DSH Tavern 既有机制。候选阶段模板投影不直接提交变量副作用；最终请求阶段才持久化。
- token 数仍为本地估算，不冒充模型 tokenizer 精确结果。
- 完整接入的是这一个插件。没有安装的其他 ST 扩展，以及 DSH 本身不存在的群聊领域能力，不伪装为已经提供。
