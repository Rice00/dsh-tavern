# DSH Tavern v1.8 变更记录

本次更新重点是写作 Skill 库、本局设置，以及游玩过程中的修改与恢复。新增从素材创建写作 Skill、按场景自动加载、按局管理后台配置，并改善长对话性能、卡片兼容和故障排查。

## 写作 Skill 与素材库

- 新增 Skill 库，按卡片 Agent、前台、后台、文生图分组，通过拖动调整用途。
- “剧本库”扩展为“剧本与素材库”，支持保存写作教学、范例等材料；导入只保存素材，不会自动创建或启用 Skill。
- 卡片工作台新增“创建写作 Skill”起始任务：选择素材后，与用户确认适用场景、禁用场景和写作要求，再提炼供前台使用的提示词。
- 写作 Skill 为独立提示词，不依赖原素材或参考文件，删除素材后仍可使用。
- 前台根据场景自动判断是否加载 Skill，先读取简介，需要时才加载全文；不同 Agent 只接收分配给自己的 Skill。
- 本局设置支持逐项开启、关闭写作 Skill，各局独立。
- 点击 Skill 名称或说明可查看 Markdown 内容，并支持编辑、预览和保存；支持删除自建及内置 Skill，删除入口直接显示在列表中。
- 内置 Skill 名称移除 `tavern-` 前缀；完善 Skill 编写指导，合并重复的文风提取入口。

## 本局设置

- 新增独立的“本局设置”页面，将配置操作从“酒馆状态”中分离，统一布局、说明与自动保存反馈。
- 集中管理玩家称呼、当前预设、用户画像、后台模型与推理强度、后台结算任务、联网搜索、场景生图开关和写作 Skill。
- 后台模型支持游玩中切换，在后续任务边界生效，沿用原后台 Agent 会话及历史。
- 不同游戏可以使用不同的后台结算配置，包括变量结算、人物姿势和人物设计档案。
- 支持多个用户画像，在本局通过下拉框选择并查看内容；切换不再重复弹出确认框。
- 生图 API 配置继续全局共用，是否开启生图由各局单独控制。
- 游玩时同时打开酒馆状态和本局设置，默认显示酒馆状态。
- 对影响提示词的切换明确说明缓存失效及首次请求的耗时、费用影响。

## 游玩修改与失败恢复

- 支持从已完成的历史轮次分叉游玩，保留原存档。
- 支持在已有游戏中应用更新后的人物卡和切换预设，保留游玩历史。
- 停止生成后，可以清除未完成回复，保留上一轮完整剧情和后台状态。
- 修复 HTTP 500 等请求失败、尚未产生正文时无法清理的问题。
- 修复未完成回复下方重复显示上一轮生图操作和失败信息的问题。
- 正文编辑、重新生成先检查宿主是否支持；不支持时提前拒绝，避免先改动剧情再失败。
- 日志、交互诊断和纯对话 TXT 导出合并为下拉菜单。
- 收窄候选项栏；状态栏标题与刷新按钮同排，简化样式并增加内容间距。

## 卡片工作台与兼容性

- 新增人物卡温和改写入口，支持另存副本及配置试玩检查。
- 卡片调试整理为 `/debug-card` Skill，按需读取游玩记录、原始输出、前后台日志、变量状态、正则及 iframe 诊断信息。
- 完善 MVU 转换指导：拆出变量初值、后台更新规则和只读状态栏；清理原卡候选项提示、按钮、正则及专用脚本，统一使用酒馆内置候选项。
- 改善交互式开场、原生开场切换、空首条开场、旧式发送按钮和输入框草稿桥接。
- 修复部分手机界面图标缺失、替换 HTML 后 iframe 高度不更新、脚本事件清理影响其他脚本等问题。
- 修复状态栏中的玩家身份宏解析，改善文本导入编码识别。
- 支持在详情中删除人物卡内置世界书，优化人物卡批量删除布局及预设提示词跨分组拖动。

## 长对话与加载性能

- 游玩历史默认展示最近 20 轮，可扩展到 100 轮，减少长对话同时挂载的内容。
- 分批激活消息 iframe，缓存未变化的历史展示结果，减少重复样式读取与完整历史复制。
- 开场资源准备增加去重、缓存和并发控制；准备开始时立即反馈，首次下载资源时显示说明。
- 核心样式随客户端打包，外部样式加载失败时保留现有样式并支持恢复。

## 提示词、安装与诊断

- 新增可开关的系统附加指令，统一前后台等 Agent 的注入位置，并保留在完整系统提示词中。
- 修复 Tavern 预设误写入全局默认配置、影响其他对话的问题。
- 命令行运行环境及数据与外部宿主隔离；修复启动界面误显示为 Desktop 版的问题。
- 安装前检查宿主版本兼容性，保留安装失败信息，允许同版本重试；修复部分依赖链接和 Git 安装文件处理问题。
- 命令行打开浏览器失败时报告错误，不再静默成功。
- 诊断 ZIP 使用无损压缩，保留排查证据并减少文件体积；补充有数量限制的交互、HTTP 拥塞、性能和生图请求前置诊断，区分正常长连接与请求卡住。
- 自动化试玩接入正式游玩会话 API，增加本地报告查看、用例选择、启动、停止及多轮前后台检查。

## 兼容性说明

- 已取消 DSH 0.1.5 / Session V3 的适配，本版本不支持该宿主版本。
- Skill 自动调用和写作效果由模型决定，不保证每次完全遵守全部写作要求。
