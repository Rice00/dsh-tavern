# DSH Tavern v1.9 变更记录

本次更新重点是剧本模式的手动控制、世界书召回，以及长对话和后台任务的稳定性。新增剧本游标切换、撤销回退、变量重新结算和人物卡分组；减少重复历史读取与旧演出指引累积，并改善失败恢复和诊断。

## 剧本模式：可以手动调整进度

- 右侧剧本块支持分页查看，每页 10 块，初始列表尽量围绕当前游标排列。
- 输入剧本块号后点击“跳转到”只改变浏览位置；点击某块的“切换游标位置”才修改剧情起点。“回到当前”可返回当前游标附近。
- 人工可以向前或向后指定游标，只允许空闲时修改，下一轮生成生效；Agent 后续仍遵循原有推进规则。
- 切换后显示成功提示和当前块标记；优化块号默认值、按钮文案及列表样式，去掉重复的正文简介。
- 剧本分块调整为约 500 个中文汉字的软预算，允许稍微超出，优先保留自然边界；标点和英文不计入汉字预算。旧存档游标按原文位置映射到新块，块号可能改变。

## 世界书召回与提示词

- 完善世界书激活条件、递归、包含组竞争及顺序处理；非固定条目从条数限制改为估算 token 软预算。
- 开场白不再参与普通关键词扫描；单个汉字关键词增加边界判断，减少误触发。
- 完善脚本激活与 MVU 规则标签识别，修复部分条目能激活却未进入实际请求的问题。
- 世界书相关性筛选复用共享后台 Agent，不再单独创建一次性“世界书筛选原型”。
- 固定世界书内容与逐轮随机、依赖状态的动态内容分开组装，减少固定提示词前缀反复变化；修复后台完整系统提示词遗漏上下文的问题。
- 增加世界书召回日志，记录扫描来源、命中和排除原因、预算及实际请求证据，便于核对“为什么召回 / 为什么没召回”。
- 历史召回去重并限制单次生成中的读取预算，重叠查询尽量只返回新增内容。已实际读取的历史轮次冷却 10 个剧情轮次；前台和后台各自计时，避免隔离上下文之间互相阻断。

## 后台任务与 MVU 恢复

- MVU 更新改为持久交付，增加任务领取、运行时心跳和中断恢复检查，改善“后台已产出，但浏览器没领到任务”的情况。
- 恢复时校验剧情分支、版本和目标消息，避免把过期更新写入新剧情；已保存结果优先接续执行，减少重复生成。
- 支持重新执行变量结算，并可附加处理意见；失败后可明确重试。
- 被替代的常驻后台实例及时释放；空闲实例约 5 分钟后释放，常驻缓存上限为 8 个。释放内存不删除历史日志。
- 减少失败初始化留下的空会话，支持接续未完成的开局流程；修复压缩回调继续持有已释放实例的问题。
- 会话页新增“当前后台 / 后台详情”。详情显示所属对话、当前与历史身份，默认折叠已确认的历史后台；页面观察到后台绑定切换时提示一次。
- 身份判断依据剧情绑定和轻量索引。旧记录或独立任务信息不足时显示待确认，不按创建时间或是否空闲判定“已废弃”。宿主原生子代理菜单本身未修改。

## 回退、清理与正文显示

- 回退按钮明确显示目标轮次；新增撤销最近一次回退，在恢复点仍有效时恢复正文、变量和对应状态。
- 回退按钮与实际操作共用原生消息目标判断，不可回退时说明原因；重新生成和编辑正文使用独立开关。
- 完善连续失败、回退标记和旧快照之后的清理判断；失败或停止后即使遗漏清理标记，也可清理未完成尾部，保留上一轮已提交剧情。
- 压缩摘要不再被误当成玩家输入，避免错误配对后回退。
- 错误提示支持批量管理；隐藏提示不再等同于隐藏剧情轮次，减少重复操作入口和并发保存冲突。
- 修复 `<UpdateVariable>`、`<initvar>` 等变量协议内容出现在初始正文中的问题。

## 长对话与上下文性能

- 新一轮生成前及前台压缩前，机械清理旧演出指引的模型可见内容。生成期间保留当前轮指引，玩家输入、助手正文和原始事件保留；旧存档无需重新开局。
- 压缩错误会识别内部的上下文超限原因，提示检查真实模型窗口或更换摘要模型，不再只显示“摘要未能变小”。
- 会话视图、模板同步和持久化更多使用版本化增量，减少完整历史传输、复制及未变化数据的重复保存。
- 正文展示投影按变更消息增量更新，缓存状态模板编译结果；版本或增量证据不匹配时回退全量重建。
- 正文流式输出不再反复触发无关的整段 DOM 扫描；空闲模板任务轮询逐步降频，有新任务时及时唤醒。
- 后台抑制信息查询保持只读，避免轮询加载后台会话或请求重叠；改善 journal 读取复用及内存保留。

## 模板兼容与人物卡管理

- 接入完整上游提示词模板浏览器运行时，补齐生命周期、命令参数、编辑与工作任务执行链路。
- 改善模板连接中断、运行时版本不匹配、保存冲突后的恢复；保留历史展示和开场状态栏，避免刷新时丢失或重复执行。
- 修复 WebKit 模块地址解析、部分旧 WebView 接口、开场运行时启动顺序，以及人物卡正则与模板显示组合问题。
- 修复所选开场对应的 MVU 初值槽位、状态栏身份宏及部分世界书模板求值问题。
- 人物卡支持分组、星标和行内分组菜单，改善分组调整后的排序与下拉菜单显示。
- 人物设计改为用户明确发起的任务，复用共享后台 Agent；精简设计档案字段。

## 安装说明与诊断

- README 补充 DSH 终端入口、Desktop 中选择 tavern Profile 的截图及红圈标注，并提供 Windows 一体版下载入口。
- 改善安装失败阶段记录、早期更新诊断和失败后的重试信息。
- 新增只读会话统计，显示已加载状态、已知磁盘大小和关联对话；不为统计加载全部聊天正文或会话日志。
- 诊断包增加浏览器与服务端请求关联、阶段耗时、并发量及事件循环延迟信息，便于区分客户端等待和服务端处理耗时。

## 兼容性与范围说明

- 当前适配 DSH **`0.1.2-rc.1`**；不支持 DSH `0.1.5` / Session V3，更新酒馆不代表可以升级到其他宿主版本。
- 回退和清理不物理删除原生日志。本次没有实现原生日志压实、原生轮号复用、跨压缩点回退或摘要重建。
- 增量优化没有消除所有全历史遍历；真实剧情过长或模型窗口配置不准确时，仍可能超限。不承诺所有存档达到相同降幅或不再卡顿。
- 本次不新增分块摘要、自动删除历史后台会话等功能；会话统计中的“待确认”也不是删除建议。
