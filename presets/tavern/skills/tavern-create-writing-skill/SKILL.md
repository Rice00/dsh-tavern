# 编写场景写作 Skill

把用户引用的现成写作教导整理成前台按场景使用的独立 Skill。

1. 阅读用户明确引用的素材。尚未引用材料时，请用户在“剧本与素材库”引用所需材料；导入动作本身只负责存储。
2. 从材料中提取明确的写作方法，以及适用场景、不适用场景。材料缺少边界、互相矛盾或用户偏好会影响取舍时，向用户询问具体场景后再定稿。已有明确答案的部分无需重复询问。方法应来自材料，不自行发明教学内容。
3. 让简介包含可识别的场景触发条件与必要排除条件。入口正文交代适用与不适用场景、共有写法，以及何时阅读哪个参考文件。不同场景的详细教学按需放入 `references/*.md`。
4. 把运行所需的教导和例子写入 Skill 自身正文或参考文件。参考文件用相对链接，并指示前台通过 `tavern_read_skill_reference` 按需读取。发布内容不得依赖原素材的路径、绑定或存在状态；删除素材后仍应完整可用。
5. 调用 `tavern_save_skill`，设置 `purpose: writing`，默认允许模型自动调用，默认分配前台 Agent。仅在用户要求时改变分配。提交 `body` 和全部新增参考文件的 `path`、`content`；修改时省略 references 会保留原文件，传入数组会替换整套参考文件。

前台根据当前场景自主选择与加载，正文中无需解释用了什么 Skill。Skill 只指导表达，人物卡事实、玩家选择及 Agent 工具权限仍按现有规则执行。

保存后简短告知名称、适用边界和分配用途。用户可以在 Skill 库中查看、停用、调整用途或删除它。
