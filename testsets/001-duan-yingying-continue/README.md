# 001 段莹莹_自由 · 三轮候选行动

- 来源：正式酒馆卡库的 `段莹莹_自由.json`，每次启动测试前同步最新内容。
- 模型：`deepseek-official / deepseek-v4-flash / high`。
- 模式：自由故事 `story`，DSH 游玩模式 `dsh`。
- 第一轮：发送 `scenario.yaml` 中的 `input`。
- 第二、三轮：通过正式界面选择上一轮第一个 `action` 候选并发送。
- 每轮：等待正文、后台结算和候选生成完成；保存输入、输出、工具结果和错误。

只需在正式酒馆修改并保存人物卡，再运行本案例。无需导出 `card.json` 或修改快照哈希。测试只读取正式卡库，内容同步到独立测试 Profile 后新开游戏；同一次测试中不重新同步。

报告 `cardSync` 记录来源、实际 SHA-256 和同步时间，每次结果目录还保存来源卡原文快照。测试副本中的临时修改会在下次启动时被正式卡覆盖。卡片 Agent 与文生图任务不属于本案例，报告标记未覆盖。
