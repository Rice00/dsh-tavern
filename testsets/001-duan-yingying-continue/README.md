| 配置 | 值 |
|---|---|
| 人物卡 | 段莹莹_自由当前工作版的固定导出快照 |
| 模式 | 自由故事 `story`，DSH 游玩模式 `dsh` |
| 开场 | 人物卡默认开场 |
| 第一轮输入 | `继续` |
| 第二轮输入 | 上一轮第 1 个 `action` 候选 |
| 第三轮输入 | 上一轮第 1 个 `action` 候选 |
| 提供商 | `deepseek-official` |
| 模型 | `deepseek-v4-flash` |
| 推理强度 | `high` |
| 后台 | 姿势与变量结算启用，模型沿用前台；人物设计未启用 |

预期：实际进入自由模式；正文非空且不拒绝；每轮后台均实际调用模型并完成结算，随后通过正式按钮生成候选项，候选落盘后才进入下一轮。记录真实输出，不预先编写标准回复。拒绝识别为规则判断，保留原文供复核。

采用本机 `resources/cards/段莹莹_自由.json`；卡片内部名称仍为“段莹莹”。通过项目现有卡片导出器生成 `card.json`，保留卡片内容与扩展；不复制正式库中的剧本绑定。独立 Profile 中导入后不绑定剧本，并以 `mode=story` 断言确认自由模式。

每次真实测试的结果以独立运行报告为准。

首次运行将本地快照导入专用测试 Profile；后续直接选择已导入的“段莹莹”新开自由模式游戏，先发送“继续”，再连续两轮通过正式界面选用上一轮的第一个行动候选。测试 Profile 持久保存在 `testsets/profiles/`，不会重复导入覆盖测试卡。
